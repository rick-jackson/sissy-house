# Sissy House

Оригінальна браузерна гра 18+ українською: гуртожиток із фембоєм і футанарі-сусідками, прогрес сісіфікації, взаємодія з кімнатами й міні-ігри.

Інтимні сцени замінені кольоровими заглушками. Усі персонажі вигадані й повнолітні.

Відкрий `index.html` або задеплоєний сайт. Прогрес пишеться в localStorage.
